These instructions are for Chromium-based browsers (e.g. Chrome, Brave, Microsoft Edge). If you are using a different browser, the instructions still work, but you will need to do a bit of figuring things out yourself.

## 1. Install Tampermonkey

Install the Tampermonkey browser extension from their [homepage](https://www.tampermonkey.net/).

- Visit the [homepage](https://www.tampermonkey.net/) and select the browser you are using from the top.
- Then download the respective `Tampermonkey` extension. Do NOT select Tampermonkey Legacy, just Tampermonkey.

![[./Attachments/Screenshot 2026-08-24 at 3.41.50 PM 1.avif]]

## 2. Accept permissions

- Open the extensions menu and click Tampermonkey.
      ![[./Attachments/Pasted image 20260824154743.avif]]

- Afterwards, you should see something like this.
      ![[./Attachments/Pasted image 20260824154801.avif]]

### Chrome/Chromium only: Allow User Scripts

Navigate to chrome://extensions. Then click the details button as shown below.
![[./Attachments/Screenshot 2026-08-24 at 3.48.43 PM.avif]]
You should see the option Allow User Scripts. Turn it on.
![[./Attachments/Screenshot 2026-08-24 at 3.48.58 PM.avif]]
Result:
![[./Attachments/Screenshot 2026-08-24 at 3.49.42 PM.avif]]

Reopen the Tampermonkey extension. The blue banner you saw earlier should disappear. Otherwise, repeat the steps again and make sure Allow User Scripts is checked.

![[./Attachments/Pasted image 20260824155021.avif]]

## 3. Install the script

Navigate to https://orangishcat.github.io/test_script.user.js. Tampermonkey should show you its script installation page. Click "Install".![[./Attachments/Screenshot 2026-08-24 at 3.59.04 PM.avif]]

## 4. Use the script

Navigate to the HW page and open an assignment.

![[./Attachments/Screenshot 2026-08-24 at 4.01.32 PM.avif]]

If you did all of the above instructions correctly, you should see a red badge with "1" in it.

Press Opt+V (Alt+V on Windows). All your answers should be filled, and you can submit whenever you wish :D

Check to make sure your answers are filled in and correct! If the script gives you a bad score, it's not my fault. You only need to do these installation instructions once. Afterwards, you can just open an assignment and Opt+V.

## Troubleshooting

- **Red badge not appearing**: You did something wrong. Restart from step 2.
- **Keypress not working**: Reload the page, wait a bit, click the assignment, then immediately press Opt+V. If the question looks different to what you've seen before in other assignments, the script might need an update.
